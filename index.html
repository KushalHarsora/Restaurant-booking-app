API Routes Documentation

/api/bookings

This route handles both retrieving and creating bookings.

GET /api/bookings/:name

Function: This GET request retrieves all bookings related to a particular name. It searches the database for entries matching the provided name and returns the results to the frontend.

Example Request:

GET /api/bookings/Kushal

Example Response:

{
  "bookings": [
    {
      "_id": "12345",
      "name": "Kushal",
      "email": "kushal@example.com",
      "phone": "1234567890",
      "date": "2025-01-02",
      "time": "14:00",
      "guests": 3
    },
    ...
  ]
}

POST /api/bookings

Function: This POST request creates a new booking and adds it to the database. It expects the booking details to be sent in the request body. Once the booking is created, the server updates the database accordingly.

Example Request:

POST /api/bookings

Example Body (JSON):

{
  "name": "Kushal",
  "email": "kushal@example.com",
  "phone": "1234567890",
  "date": "2025-01-02",
  "time": "14:00",
  "guests": 3
}

Example Response:

{
  "message": "Booking successfully created!"
}

/api/slots

This route helps check for available time slots on a particular date.

GET /api/slots/:date

Function: This GET request checks for available slots on a particular date. The server searches for available times on that date and responds with the available slots, if any.

Example Request:

GET /api/slots/2025-01-02

Example Response:

{
  "availableSlots": [
    "09:00 AM",
    "11:00 AM",
    "01:00 PM",
    "03:00 PM"
  ]
}

Example (No slots available):

{
  "availableSlots": []
}
